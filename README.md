# A股外部冲击识别系统

量化识别外部突发事件对A股市场的影响，区分外部冲击导致的下跌与市场内生悲观预期导致的下跌。

## 🎯 项目目标

- 识别外部突发事件（地缘政治、原油供应链、加密货币异动等）对A股的影响
- 区分外部冲击导致的下跌与市场内生悲观预期导致的下跌
- 提供完整的量化分析和可视化界面

## ✨ 核心功能

### 1. 事件检测
- 支持11种事件类型识别
- 关键词匹配引擎
- 历史事件库（13个典型事件）

### 2. 内生基准拟合模型
- 60日滚动窗口多元线性回归
- 计算残差作为外生冲击代理变量
- 自动因子筛选

### 3. 传导路径验证
- 成本输入型传导验证
- 避险情绪型传导验证
- 加密货币传染型传导验证

### 4. 行业横截面验证
- 板块分化度分析
- 原油/加密货币敏感度检验
- 横截面相关性分析

### 5. 统计显著性检验
- T检验、F检验
- 贡献度拆分
- 置信度评估

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Conda（推荐）

### 安装依赖

```bash
# 创建虚拟环境
conda create -n quant_dev python=3.11
conda activate quant_dev

# 安装依赖
pip install -r requirements.txt
```

### 启动 Web 界面

```bash
streamlit run app.py
```

### 使用 Python API

```python
from src.models.shock_detector_system import ExternalShockDetector

# 初始化系统
detector = ExternalShockDetector()

# 分析特定事件
result = detector.analyze_event(
    event_text="中东爆发战争，原油运输受阻",
    event_date="2024-01-15"
)

print(result.summary)
```

## 📊 支持的事件类型

| 类别 | 事件类型 | 示例 |
|------|----------|------|
| 地缘政治 | 战争冲突、恐怖袭击 | 中东战争、霍尔木兹海峡 |
| 原油供应链 | 产油国动荡、运输中断 | 原油减产、油田遇袭 |
| 加密货币 | 交易所暴雷、价格崩盘 | FTX、BTC暴跌、Luna崩盘 |
| 汇率冲击 | 央行干预、快速贬值 | 日元干预、人民币破7 |
| 利率冲击 | 国债收益率剧变 | 硅谷银行、英国养老金危机 |
| 大宗商品 | 黄金、工业金属异动 | 黄金创新高 |

## 🔌 数据源

### 免费数据接口
- **akshare**: A股行情、板块数据、北向资金
- **yfinance**: 全球市场、加密货币、大宗商品

### 数据获取能力
- A股实时行情和历史数据
- 板块轮动数据
- 北向资金流向
- 港股、美股市场数据
- 比特币、以太坊等加密货币价格
- 原油、黄金等大宗商品价格
- 汇率数据（美元指数、人民币汇率）
- 国债收益率数据

## 📈 使用示例

### Web 界面

1. 选择事件类型（如"地缘政治冲突"）
2. 输入新闻描述或使用默认模板
3. 点击"开始分析"
4. 查看分析结果：

   - 冲击类型和置信度
   - 传导路径验证
   - 行业横截面验证
   - 贡献度拆分
